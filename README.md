## 关键洞察

- **总投入55万**（初始10万 + 9年追加45万），10年后变为 **345.96万**，净赚 **290.96万**
- 第6年（2031）资产突破百万美元，此后进入指数加速期
- 最后3年（2033—2035）每年收益分别为 45万、60万、80万，**3年赚的钱超过前7年总和**
- 第10年单年收益（79.84万）已超过前4年累计投入（20万）的4倍——复利的本质是后期爆发
- 资产/投入比从第1年的1.3x攀升至第10年的 **6.29x**
